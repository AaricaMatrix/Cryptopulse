Overview

A self-initiated project, scoped and labeled honestly.

Built to have real, defensible Web3-domain evidence before applying somewhere that lives and breathes crypto — not to claim a trading system that doesn't exist. Every design choice below has a reason, and every reason is one you can say out loud in an interview.

What this is

  • A real pipeline — live HTTP calls to CoinGecko and the Fear & Greed Index, not a static sample dataset.
  • An honest heuristic — z-score anomaly detection, chosen deliberately for a 90-point dataset, not dressed up as a trained model.
  • Tableau-ready — three clean CSVs that open with no manual type-fixing.
  • Fully explainable — every column, every threshold, every join has a documented reason.

What this isn't

  • Not a trading system — no buy/sell logic, no backtesting, no signals for sale.
  • Not per-coin sentiment — the Fear & Greed Index is market-wide; the pipeline never pretends otherwise.
  • Not production-grade ML — a rolling z-score, not an Isolation Forest, because the dataset doesn't justify one here.
  • Not real-time — one batch pull is enough for exploratory analysis; this isn't a live dashboard.

Six steps, each in its own file.

One command runs the whole thing. Nothing here is one giant script — each stage is isolated enough to test, read, and swap out on its own.

Data sources

Two free, keyless APIs. Nothing to leak, nothing to configure.

No API keys anywhere in this project — both sources below are public and require none, which means there's also nothing sensitive to accidentally commit.

CoinGecko

keyless
Per-coin daily price, volume, and market cap history.
GET /coins/{id}/market_chart
  ?vs_currency=usd&days=90&interval=daily
  • prices[timestamp_ms, price] pairs
  • total_volumes[timestamp_ms, volume] pairs
  • market_caps[timestamp_ms, cap] pairs
  • coin ida slug, not a ticker — "bitcoin", not "BTC"

Fear & Greed Index

keyless
Market-wide sentiment via Alternative.me — one reading per day, not per coin.
GET api.alternative.me/fng/
  ?limit=90&format=json
  • value0–100 sentiment score
  • value_classificatione.g. "Extreme Fear"
  • timestampunix seconds — not ms, unlike CoinGecko
  • scopewhole market, joined onto every coin by date
Methodology

Three numbers, each one defensible out loud.

Nothing computed here needs hand-waving. If asked to explain any column in the exported CSVs, the answer is below.

Daily return

rt = (Pt − Pt-1) / Pt-1

Simple percent change, not log return — easier to explain in an interview, and the difference doesn't matter at this scale. Calculated per coin, so one coin's history never bleeds into another's.

Rolling volatility

σ7d = stdev(rt … rt-6)
σ30d = stdev(rt … rt-29)

Standard realized volatility: how hard the price is swinging, regardless of direction. A rising 30-day figure means the recent past has been rougher than the month before it.

Volume z-score

z = (Vt − μ30d) / σ30d
flag if |z| > 2

How many standard deviations today's volume sits from its own trailing 30-day normal. A simple, well-known outlier heuristic — not a trained model.

Anomaly detection

Why z-score, and not Isolation Forest?

A fair question if it comes up — especially since Isolation Forest was the right call on a larger dataset elsewhere.

Volume anomalies against price — illustrative

synthetic sample, not live data
Dataset size decided this, not preference. Isolation Forest earns its complexity on larger datasets where it can actually learn the shape of "normal." With 90 daily points per coin, a rolling z-score against a 30-day baseline is simpler, transparent, and just as effective — and it's the version of this reasoning that holds up when someone asks "why didn't you use the fancier method?"

Setup

One command, no API keys.

Clone it, install, run it. Outputs land in data/ and charts/ — point Tableau at merged_daily.csv when it's done.

terminalbash
# clone and enter the project
git clone https://github.com/AaricaMatrix/cryptopulse.git
cd cryptopulse

# install dependencies
pip install -r requirements.txt

# run the full pipeline
python -m src.pipeline

# check what landed
head data/merged_daily.csv
